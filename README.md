## 🧠 Skills behind my websites

Each site pushes me to learn something new. This is what I've used to build mine:

- **From design to code**: translating a Figma layout into pixel-accurate, responsive pages
- **Layout and styling**: mobile-first approach, fluid typography, a colour system built on CSS variables, light and dark themes
- **Interactivity**: DOM scripting, data-driven rendering (e.g. a menu generated from a data object), tabs, forms
- **Motion and 3D**: keyframe animations, scroll-triggered reveals, a real-time 3D scene with three.js
- **Performance**: pausing animations off-screen, no build step, lightweight single-file pages
- **Robustness**: safe output escaping, fallbacks when JS or WebGL isn't available, respect for "reduce motion"
- **Shipping**: Git, GitHub, deploying static sites
